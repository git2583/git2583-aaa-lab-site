# InsightDigest: AI 기반 지능형 문서 요약 서비스

### 결과물

**InsightDigest (인사이트 다이제스트)**
- 한 줄 소개: 방대한 기술 문서를 분석하여 핵심 인사이트와 3줄 요약을 제공하는 AI 도구입니다.
- 결과물 링크: [GitHub Repo](https://github.com/example/insight-digest)
- [InsightDigest 실행화면](https://github.com/example/insight-digest)

### 만든 과정 및 삽질

- **시도 1**: 단순 GPT-4 API 호출을 통한 요약.
- **문제 발견**: 컨텍스트 윈도우 초과 및 긴 문서의 중간 내용 유실 발생.
- **해결 과정**: 
    - LangChain의 `RecursiveCharacterTextSplitter`를 도입하여 문서를 의미론적으로 분할.
    - 'Map-Reduce' 및 'Refine' 방식을 혼합하여 요약의 일관성과 상세함을 동시에 확보.
    - 한국어 특유의 존댓말/반말 혼용 문제를 해결하기 위해 시스템 프롬프트에 스타일 가이드 추가.

### 인사이트

- **배운 점**: LLM 애플리케이션에서 가장 중요한 것은 모델 자체가 아니라, 모델이 처리하기 좋게 데이터를 가공하는 '데이터 파이프라인' 설계임을 배웠습니다.
- **놀란 점**: 생각보다 토큰 비용이 효율적으로 관리될 수 있다는 점과, 복잡한 논문도 구조화된 마크다운으로 잘 변환해준다는 점에 놀랐습니다.

### 다시 한다면?

- **더 나은 접근**: 현재의 동기 방식 처리 대신, Celery와 Redis를 사용한 비동기 처리 구조를 도입하여 대용량 문서도 타임아웃 없이 처리하고 싶습니다.
- **다음 스텝**: PDF 파일 업로드 기능을 추가하고, 요약된 내용을 Slack이나 노션으로 바로 전송하는 자동화 기능을 구현할 계획입니다.
