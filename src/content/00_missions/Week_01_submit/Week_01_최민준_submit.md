### 결과물

**FastAPI 기반 비동기 문서 처리 API API**
- 한 줄 소개: 대용량 PDF 요약 요청을 처리하고 상태를 추적할 수 있는 백엔드 API 서버입니다.
- 결과물 링크: [Swagger UI](http://localhost:8000/docs)

### 만든과정 및 삽질

- **시도 1**: 동기(Sync) 방식으로 API를 구현함.
- **문제 발견**: 요약에 30초 이상 걸리다 보니 클라이언트 연결이 타임아웃으로 끊김.
- **해결 과정**: FastAPI의 `BackgroundTasks`를 도입하여 요청 즉시 Task ID를 반환하고, 클라이언트가 나중에 결과를 조회하는 비동기 방식으로 구조 변경.

### 인사이트

- **배운 점**: 오래 걸리는 작업은 반드시 비동기로 처리해야 서버 리소스를 효율적으로 쓸 수 있음을 배웠습니다.
- **인사이트**: Pydantic 모델을 통한 데이터 검증이 런타임 에러를 줄이는 데 얼마나 강력한지 체감했습니다.
