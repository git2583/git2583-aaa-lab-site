# AAA 봇 인사이트 (누적)

프로젝트 진행 과정에서 도출된 LLM 및 자동화 봇 활용에 대한 핵심 인사이트 모음입니다.

## 기술 인사이트
- **데이터 파이프라인의 중요성**: LLM의 성능보다 입력 데이터의 전처리(Parsing) 품질이 결과물에 더 큰 영향을 미침. (박지훈)
- **프롬프트 언어의 영향**: 한국어 요약 요청 시에도 영문 가이드라인을 포함한 프롬프트가 논리적 구조 형성에 유리함. (이서아)

## 운영 인사이트
- **비동기 설계의 필수성**: 사용자 경험 측면에서 10초 이상의 대기 시간이 발생하는 작업은 반드시 상태 추적형 비동기 UI를 제공해야 함. (최민준)
- **템플릿의 힘**: 표준화된 마크다운 템플릿 제공만으로도 팀원 간 데이터 파편화가 80% 이상 감소함. (양파토끼)

## 발전 방향
- 현재의 단순 요약 봇에서 문서 간의 연관 관계를 추론하는 '지식 그래프 봇'으로의 진화 필요.
